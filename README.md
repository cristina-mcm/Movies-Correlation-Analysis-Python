# Movie Correlation Analysis

This project explores relationships between movie budgets, gross revenue, and other attributes using Python.

## Tools

- Python
- pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis

- Examined missing values and data types.
- Extracted release years and converted columns to appropriate data types.
- Analyzed correlations between numerical and categorical variables.
- Visualized relationships using scatter plots, regression lines, and heatmaps.

## Files

- `movies.csv` — Movie dataset.
- `movies_correlation_analysis.ipynb` — Jupyter Notebook containing the analysis.
