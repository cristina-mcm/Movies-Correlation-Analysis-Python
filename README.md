# Movie Correlation Analysis

This project explores relationships between movie budgets, gross revenue, and other attributes using Python.

## Analysis Process

- Inspected the dataset for missing values and duplicate records.
- Converted columns to appropriate data types.
- Explored the relationship between budget and gross revenue using a scatter plot and regression line.
- Calculated Pearson correlation coefficients for numerical variables.
- Converted categorical variables into numerical codes for broader comparison.
- Visualized the results with correlation matrices and heatmaps.

## Key Findings

- Budget had a strong positive correlation with gross revenue.
- Audience votes also had a notable positive correlation with gross revenue.
- Production company had a much weaker relationship with gross revenue than originally expected.
